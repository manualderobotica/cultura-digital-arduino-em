# Cultura Digital e Projetos com Arduino

Repositório para aulas de **Cultura Digital** e **Projetos com Arduino em C/C++** destinado aos alunos do **Ensino Médio**.

## 🎯-‍♂️ Sobre este repositório

Este projeto reúne:
- **Projetos Maker**: Automáo, IoT, Robustica
- **Programação Embarcada**: C/C++ para Arduino, ESP32, microcontroladores
- **Cultura Digital**: Conceitos, ferramentas e boas práticas de cidadania digital
- **Exemplos de Código**: Projetos prontos e exercícios práticos

## 📄 Estrutura de Pastas

```
â≊-- /projetos              # Projetos completos de Arduino
â≊-- /exercicios            # Exercícios e desafios
â≊-- /exemplos              # Códigos de referência
â≊-- /recursos              # Documentos e materiais
â≊-- /cultura-digital       # Módulo de Cultura Digital
```

## 🚀 Como Começar

1. Clone este repositório na sua máquina
2. Instale o Arduino IDE ou PlatformIO
3. Navegue pelos exemplos e projetos
4. Siga as instruções de cada pasta

## 📚 Requisitos

- Arduino IDE ou PlatformIO
- Conhecimento básico de C/C++
- Hardware: Arduino, ESP32, sensores (conforme projeto)
